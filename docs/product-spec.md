# Orbit 产品说明

## 产品目标

Orbit 是一个轻量 AI 网页应用生成工作台。用户用自然语言描述需求，系统生成一份可运行的单文件 HTML，并在隔离预览区中直接展示。用户可以继续对话修改应用，平台保存项目、消息和代码版本。

## 目标用户与核心任务

目标用户是不熟悉前端开发、但希望快速验证网页工具想法的产品经理、设计师和小团队成员。核心任务是从一句自然语言需求出发，在几分钟内得到一个可以操作的网页原型。

## 第一阶段范围

- 完成 Next.js、TypeScript 和 Tailwind 项目骨架。
- 完成项目列表、对话区、生成状态、预览区和代码区。
- 使用内置生成器实现无需数据库的最小闭环。
- 支持任务管理器、贷款计算器、客户看板和通用灵感看板四类结果。
- 生成结果通过 `iframe sandbox="allow-scripts"` 运行。
- 支持桌面/手机预览、代码查看与复制。
- 页面在桌面和移动设备上均可使用。

第一阶段的“生成”来自本地规则和模板，界面明确标注为本地生成模式。它用于提前验证产品交互，不冒充真实模型能力。

## 第二阶段范围

- 使用服务端 `/api/generate` 接口真实调用模型，密钥只从服务端环境变量读取。
- 首次生成传入自然语言需求；后续修改在同一请求结构中附带当前应用。
- 模型输出统一为 `title`、`summary`、`html`，并经过结构、长度和 HTML 安全校验。
- OpenAI 模型使用 Responses API JSON Schema；DeepSeek 使用 Chat Completions JSON 模式。
- 输入最多 2,000 字符，HTML 最多 120,000 字符，模型调用 55 秒超时。
- 单个服务实例按来源限制为每 5 分钟 5 次请求。
- 生成失败、超时、限流或校验失败时不替换当前预览，并提供重试按钮。
- 预览继续使用 `sandbox="allow-scripts"`，服务端注入 CSP 阻断外部连接与资源。

## 第三阶段范围

- 浏览器首次访问时通过 Supabase Auth 创建匿名用户，会话保存在当前浏览器。
- `projects` 保存项目元数据和当前版本指针。
- `messages` 保存成功生成对应的用户与助手消息。
- `code_versions` 保存每次成功生成的完整不可变 HTML。
- `save_generation` 数据库函数在一个事务内写入项目、消息、版本并更新当前版本。
- 页面启动后恢复最近项目、完整对话和当前 HTML。
- 历史版本抽屉按版本号倒序展示，`restore_version` 只切换当前版本指针并记录恢复消息。
- 三张表启用 RLS，只向 `authenticated` 角色授予所需最小权限，并使用 `auth.uid()` 隔离数据。
- Supabase 未配置或连接失败时明确显示状态；未配置时仍可临时体验模型生成，但刷新不会保留。

## 后续阶段

1. 完成 Vercel 部署、生产环境变量和公开演示地址。
2. 将单实例限流升级为基于匿名身份的共享限流。
3. 增加项目删除和匿名账号升级能力。

## 最终验收标准

- 游客能够创建项目并真实调用模型生成应用。
- 生成应用具备可操作的按钮、输入、筛选或计算逻辑。
- 用户可以通过追加需求修改当前应用。
- 刷新后项目、消息和代码保持存在。
- 每次成功生成创建一个历史版本，支持恢复。
- 失败时保留最后一个可用版本并允许重试。
- 模型密钥只存在于服务端，预览代码无法读取平台身份和密钥。
- 线上地址可公开访问，GitHub 仓库和运行文档完整。

## 明确不做

- 在线容器与任意 npm 依赖安装。
- 支付、团队协作和复杂第三方登录。
- 多智能体并行调度。
- 大型多页面应用生成。

## 演示主路径

1. 输入“生成一个学习任务管理器，支持添加、完成、删除和筛选任务”。
2. 查看真实生成阶段，等待右侧预览更新。
3. 在预览中添加和完成任务。
4. 追加“增加统计区并改成深色风格”。
5. 刷新页面，确认项目和对话恢复。
6. 查看历史版本并恢复旧版本。
