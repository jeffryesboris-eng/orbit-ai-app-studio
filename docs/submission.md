## 实现思路

Orbit 将一次生成限制为完整的单文件 HTML。用户需求由 Next.js 服务端接口发送给模型，模型统一返回 `title`、`summary` 和 `html`。服务端对结构、长度和危险能力进行校验，通过后才把结果交给浏览器。生成页面在 `sandbox="allow-scripts"` 的 iframe 中运行，无法读取主应用身份或服务端密钥。

Supabase Auth 为首次访问者创建匿名身份。项目、成功对话和每次生成的完整 HTML 分别保存在 `projects`、`messages` 和 `code_versions` 中。数据库函数在同一事务里保存一次成功生成，RLS 使用 `auth.uid()` 隔离用户数据。历史恢复只切换当前版本指针，不修改旧版本。

## 关键取舍

1. 只生成单文件 HTML、内联 CSS 和原生 JavaScript，以换取稳定、快速且容易隔离的演示体验。
2. 使用 iframe `srcDoc` 和最小 sandbox 权限执行生成代码，并在服务端阻止外部资源与网络 API。
3. 使用 Supabase 匿名身份降低首次体验门槛；数据与当前浏览器身份绑定。
4. 使用数据库函数保证项目、两条消息和代码版本一起写入，避免部分保存。
5. 当前频率限制保存在单个运行实例内，足够用于受控演示；公开规模化使用需要共享限流。

## 已知限制

- 匿名会话存于浏览器；清除站点数据或更换设备后无法找回原身份。
- Vercel 多实例之间不共享内存限流计数。
- 生成结果限定为单页应用，不能安装 npm 包或访问外部网络资源。
- 模型质量和响应时间受所选模型服务影响。

## 继续投入时的优先级

1. 用 Redis 或数据库实现按用户/IP 的共享限流与每日额度。
2. 为公开匿名注册增加 Cloudflare Turnstile，并增加过期匿名数据清理。
3. 支持匿名账号升级为邮箱或 OAuth 账号，保留已有项目。
4. 增加版本差异比较、项目重命名和删除。
